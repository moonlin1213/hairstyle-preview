# Hairstyle Preview · 发型预览设计

一个用于 Codex 的发型试戴技能。上传清楚的人像照片，即可生成同一人物的多款发型对照图，并获得基于可见特征和个人偏好的视觉建议。

默认采用奶油米白与深咖色的中文报告版式，包含 **15款发型、3行×5列网格、发型名称与简短描述**。也可以提供自己的版式参考，或指定短发、刘海、卷度、发色及维护偏好。

## 使用

将这个仓库复制到个人 Codex 技能目录 `~/.codex/skills/hairstyle-preview`。已有同名技能时请先比较内容，避免直接覆盖。

在 Codex 中上传照片，并输入：

```text
用 $hairstyle-preview，根据这张照片设计适合尝试的发型，
生成一张多种发型预览参考图。
```

可以补充“只看短发”“不要刘海”“希望好打理”等要求。无需每次上传版式图。

该技能需要运行环境提供内置图像生成与图像查看工具。它是一套技能指令与版式预设，不包含独立图像模型，也不需要仓库中的 API 密钥配置。

## 设计原则

- 以本次上传的照片为人物来源，尽量保留五官、脸型、表情、衣服和自然皮肤细节。
- 样式参考只影响排版与美术风格，不借用参考图模特的脸。
- 款式按当前照片和偏好调整，覆盖明显不同的长度、刘海、分缝、卷度与扎法。
- “优先尝试”等建议属于视觉判断；实际剪烫效果还取决于发质、发量和发型师的处理。
- 生成后检查人物相似度、发型差异、卡片数量、文字及裁切，再保存最终图片和提示词。

## 隐私范围

仓库仅包含通用文字指令与预设，不包含真人照片、生成的人像示例、个人对话记录、个人绝对路径或密钥。

使用时上传的照片会由所用运行环境和图像生成工具处理；是否保留以及如何处理，取决于该环境与服务的设置。本技能不保证离线处理，也不自动公开发布照片或生成结果。
