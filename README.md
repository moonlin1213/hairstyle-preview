# Hairstyle Preview · 发型与发色预览设计

一个用于 Codex 的发型与发色试戴技能。上传清楚的人像照片，即可按请求生成同一人物的多款发型，或多种发色与染色方式对照图，并获得视觉建议。

两种模式默认都采用奶油米白与深咖色的中文报告版式，包含 **15款方案、3行×5列网格、名称与简短描述**。也可以提供自己的版式参考，或指定长度、刘海、卷度、发色及维护偏好。

- **发型模式**：保留原发色，比较长短、刘海、分缝、卷度和扎法。
- **发色模式**：保持同一发型、肤色与光线，比较自然发色、彩色方向，以及细束挑染、手扫染、渐变染、挂耳染、内层染等颜色分布。

## 使用

将这个仓库复制到个人 Codex 技能目录 `~/.codex/skills/hairstyle-preview`。已有同名技能时请先比较内容，避免直接覆盖。

在 Codex 中上传照片，并输入：

```text
用 $hairstyle-preview，根据这张照片设计适合尝试的发型，
生成一张多种发型预览参考图。
```

可以补充“只看短发”“不要刘海”“希望好打理”等要求。无需每次上传版式图。

想看发色与染色方式时：

```text
用 $hairstyle-preview，保留这张照片里的发型，
设计一张15款发色与染色方式预览参考图。
```

可以补充“只看自然棕色”“想试局部挑染”“希望保留深色发根”等偏好。只要求发色时不会额外生成发型图；明确要两者时，默认分别制作两张对照图。

该技能需要运行环境提供内置图像生成与图像查看工具。它是一套技能指令与版式预设，不包含独立图像模型，也不需要仓库中的 API 密钥配置。

## 设计原则

- 以本次上传的照片为人物来源，尽量保留五官、脸型、表情、衣服和自然皮肤细节。
- 样式参考只影响排版与美术风格，不借用参考图模特的脸。
- 款式按当前照片和偏好调整，覆盖明显不同的长度、刘海、分缝、卷度与扎法。
- 试发色时保持原有发长、轮廓与光线，染色位置清楚；不通过美白皮肤或换发型制造颜色效果。
- “优先尝试”等建议属于视觉判断；实际剪烫效果还取决于发质、发量和发型师的处理。
- 发色预览不保证实际显色，也不从照片断言是否需要漂发；头发底色、染发史、发质和光线都会影响实际结果。
- 生成后检查人物相似度、方案差异、卡片数量、文字及裁切，再保存最终图片和提示词。

## 隐私范围

仓库仅包含通用文字指令与预设，不包含真人照片、生成的人像示例、个人对话记录、个人绝对路径或密钥。

使用时上传的照片会由所用运行环境和图像生成工具处理；是否保留以及如何处理，取决于该环境与服务的设置。本技能不保证离线处理，也不自动公开发布照片或生成结果。
