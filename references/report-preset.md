# 奶油色发型参考海报预设

用户没有新样式要求时使用。这个预设复用已认可的报告形式，不依赖任何旧照片。用户有新参考时优先跟随新参考。

## 版式

竖版约2:3。奶油米白纸张背景，深咖色宋体主标题，浅米色圆角肖像卡，香槟金编号、小面积细线植物装饰与分隔线。人物使用自然摄影质感，发丝与发际线真实。中文清楚，图片为主，避免密集小字和水印。

顶区约15%：大标题“发型预览参考”，副标题“同一张脸 · 15款发型对照”，小字“保留五官与脸型，看看不同长度、刘海和卷度”。右上可放当前输入人物的原发型小像，标“你的原发型”。只描述本次内容，不填未经验证的“个人特点”。

主体严格3行×5列，共15款。每行分类条默认“优先尝试”“日常百搭”“个性尝试”，每格编号01–15，配发型名称与一句约8–12字短描述。推荐顺序应随人物与偏好调整，不能照抄样式图对另一位人物的“最适合/不建议”结论。

底部：“选发型时，可以这样看”，三个小块为“刘海”“长度”“卷度”，列出本次真实出现的选项。脚注“效果为发型试戴预览，剪烫前可与发型师结合发质沟通。”

## 提示词骨架

按本次输入填写，不把占位说明直接交给生成器。文字确定后要求按原文呈现。

```text
Use case: identity-preserve
Asset type: 高分辨率竖版中文发型试戴参考海报
Input images: 明确指出哪张是唯一身份来源，哪张仅为版式参考。
Primary request: 根据当前人物照片制作15款不同发型的对照，使用奶油米白与深咖色报告版式。
Identity invariants: 写出当前照片中应保留的五官、脸型、表情、衣服与自然标记，只改变头发。
Composition: 顶部标题与原发型小像，主体3行×5列15款，底部简洁选择提示。头顶和发型轮廓完整。
Hairstyles: 按最终选定顺序逐项写出编号、名称、长度、刘海、分缝、卷度或扎法及短描述。
Text verbatim: 本次完整中文标题、分类、15个标签和底部文字。
Constraints: 所有卡片同一人、同一表情与视角；不瘦脸、不改五官、不换成样式图模特、不加浓妆。自然发丝，无水印，不给出未经验证的发质或适合度断言。
```
